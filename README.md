# Anis Raihan — Academic Website

This folder contains the website files for GitHub Pages.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload the contents of this folder (including `index.html`, `assets/`, and `AnisRaihan_CV.pdf` if included) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site uses a relative image path (`assets/raihan-portrait.jpg`) so it works when published from the repository root.
